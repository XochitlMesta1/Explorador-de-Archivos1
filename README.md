# Explorador de Archivo

Aplicación de escritorio desarrollada en C# y .NET 8 que integra herramientas para exploración de archivos, reproducción multimedia, grabación de audio y video, captura mediante cámara web y gestión de archivos desde una interfaz moderna e intuitiva.

# 2.Features
- Explorador de archivos.
- Reproductor de música.
- Reproductor de video.
- Grabadora de audio.
- Captura de fotografías.
- Grabación de video mediante cámara web.
- Visualizador de imágenes.
- Conversor de archivos.
- Integración con SQL Server.
- Interfaz personalizada con tema oscuro.

# 3.Tech
- C#
- .NET 8
- Windows Forms
- SQL Server
- NAudio
- LibVLCSharp
- AForge.NET
- Newtonsoft.Json
- Accord.Video.FFMPEG

# 4.Installation 
```bash
git clone https://github.com/TU-USUARIO/Explorador-de-Archivos.git

cd Explorador-de-Archivos

dotnet restore

dotnet build

dotnet run
```

# 5.Run Locally

1. Abrir la solución en Visual Studio 2022.

2. Restaurar paquetes NuGet:

```powershell
dotnet restore
```

3. Compilar el proyecto:

```powershell
dotnet build
```

4. Ejecutar la aplicación:

```powershell
dotnet run
```
